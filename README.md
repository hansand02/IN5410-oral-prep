# IN5410 Oral Prep

Single-page oral-exam drill for **IN5410 Energy Informatics** (UiO).

Open `index.html` in any browser — no build step, no dependencies.

## Features
- **Single Q mode** — random draw, reveal hint + follow-ups + cross-lecture links
- **Mock oral (30+30)** — 5 random questions, 30 min prep + 30 min delivery, with timer
- **Browse all** — full catalogue grouped by lecture
- **90 s speak timer** for practising spoken answers
- Keyboard: `space` draw · `r` reveal · `s` speak-timer
